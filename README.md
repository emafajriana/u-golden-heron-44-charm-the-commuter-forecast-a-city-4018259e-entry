One line of weather forecast, at most 140 characters, for a city that
does not exist — written to charm a bored commuter at a rainy bus stop.

## The entry

> In Crumplewick, rain till nine, then sun — the bus you sprinted for waits at the kerb, doors open, driver smiling.

(114 characters.)

## How to run

```sh
python3 main.py
```

Writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` (or `/output` by default),
verifying the text is 1–140 characters, not only whitespace, and
reading it back byte-for-byte. Standard library only.
